# rubiks-cube-solver

This project is a Rubik's Cube Solver and Simulator designed to demonstrate algorithms and logical problem-solving techniques used to solve the classic Rubik’s Cube puzzle. The application allows users to scramble the cube, perform rotations, and visualize the solving process. It highlights programming concepts such as data structures, algorithms, and interactive user interface design using modern web technologies.

Features :-
Rotate cube faces interactively
Scramble the cube randomly
Solve the cube using algorithms
User-friendly interface
Real-time cube visualization
Responsive design

Technologies Used :-
HTML5 — Structure of the web page
CSS3 — Styling and layout
JavaScript — Cube logic and interactivity
Bootstrap — Responsive design framework

How to Run the Project :-
Download or clone the repository
Open the project folder
Run the index.html file in a web browser
Start interacting with the Rubik’s Cube
